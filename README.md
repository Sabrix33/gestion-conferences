# Gestion des conférences

## Description
Ce projet est une application Web développée avec **Angular 21** pour gérer des conférences et faciliter les inscriptions des utilisateurs.

## Fonctionnalités
- Afficher la liste des conférences.
- Rechercher une conférence par son titre.
- Afficher les détails d'une conférence sélectionnée.
- Afficher les dates et les titres formatés.
- Consulter les places disponibles.
- S'inscrire à une conférence.
- Afficher les profils, les amis et les notifications.

## Technologies utilisées
- Angular 21
- TypeScript
- HTML
- CSS

## Installation

Installer les dépendances du projet :

```bash
npm install
```

## Lancement

Démarrer l'application :

```bash
ng serve
```

Ouvrir ensuite le navigateur à l'adresse :

http://localhost:4200/

## Structure du projet

L'application est organisée en plusieurs composants :

- Header
- Navbar
- ProfileUser
- FriendsList
- NotificationList
- ConferenceList
- ConferenceDetails
- Footer
